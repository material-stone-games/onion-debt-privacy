기기의 게임 데이터를 지우려면

  1. Android 설정에서 앱 → 양파로 빚 갚기 → 저장공간으로 이동합니다.
  2. 데이터 삭제를 누르거나 앱을 제거합니다.

게임 진행, 엔딩·업적·기록, 설정, 기기에 저장된 프리미엄 구매 여부가 삭제됩니다. 개발자 서버에 저장하지 않으므로 삭제 후 복구할 수 없습니다. 온라인 랭킹 기록은 이것으로 지워지지 않으니, 앱을 지우기 전에 아래 방법으로 먼저 지워 주세요. Google Play의 유효한 구매 내역은 지워지지 않으며, 같은 Google 계정으로 앱의 구매 복원을 누르면 되찾을 수 있습니다.

온라인 랭킹 기록을 지우려면

  1. 앱 타이틀에서 도감 → 시즌으로 이동합니다.
  2. ‘그만두고 기록 지우기’를 누르고 확인합니다.

서버(Google Firebase)에 올린 랭킹 이름·시즌 기록과 익명 계정이 바로 삭제됩니다. 기기의 기록은 남습니다. 지우지 않아도 각 기록은 올린 때부터 약 4개월 뒤 자동으로 삭제됩니다. 온라인 랭킹에 참여하지 않았다면 지울 서버 기록이 없습니다.

앱을 이미 지웠다면 아래 이메일로 랭킹 이름과 참여한 시즌을 알려 주세요. 확인한 뒤 해당 기록을 지우고 결과를 알려 드립니다.

광고 데이터를 관리하려면

광고는 Google AdMob이 처리합니다. Android 설정의 광고 ID 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있고, Google 계정의 데이터는 Google 계정의 데이터 및 개인 정보 보호에서 관리할 수 있습니다. 개발자는 이 데이터를 개별 사용자 단위로 보관하지 않아 직접 지울 수 없습니다.

개발자에게 요청하려면

  1. 위 이메일로 제목을 ‘양파로 빚 갚기 데이터 삭제 요청’으로 보내 주세요.
  2. 요청 내용을 적어 주시면 처리 결과나, Google이 처리하는 정보라면 해당 절차를 안내해 드립니다.

요청 이메일은 처리에만 사용하고 목적이 끝나면 삭제합니다. 회원가입이 없어 따로 삭제할 계정은 없습니다(온라인 랭킹의 익명 계정은 위 방법으로 함께 지워집니다). Google Play 주문·결제 내역은 Google의 정책과 절차를 따르며, 데이터 삭제 요청은 구매 취소나 환불 요청과 별개입니다.
